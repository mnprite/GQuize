==================================================
RULES FOR CHECKING ANSWERS (apply to EVERY question)
==================================================

RULE 1 - Ignore uppercase/lowercase, spacing and the "+" sign.
Capital or small letters never matter. "HAS TO", "Has to", "has + to", "has+to" are all the same. "Has + not + to" = "has not to". Ignore extra spaces. Check the meaning, not the capitalization.

RULE 2 - Contractions are accepted.
Treat these as the same as the full form: isn't = is not, aren't = are not, hasn't = has not, haven't = have not, hadn't = had not, wasn't = was not, weren't = were not, doesn't = does not, don't = do not, didn't = did not, won't = will not. Example: "doesn't have to" = "does not have to". Also, for "do not have / does not have / did not have", the final word "to" is optional (the key may show it without "to").

RULE 3 - Accept any valid answer.
If a question has several valid answers, I only need to give ONE valid answer to be marked correct.
Example: Question: करना है  Valid: Is to, Am to, Are to, Has to, Have to.  My answer: "is to"
Result:
Correct ✅
Other answers: Am to, Are to, Has to, Have to
(then the next question)
Show under "Other answers" only the valid answers I did NOT give.

RULE 4 - Do not show "Other answers" when my answer is complete.
If the question has only ONE valid answer and I gave it, show only "Correct ✅" and go to the next question.
Example: Question: नहीं करना होगा / पड़ेगा  Valid: Will not have to.  My answer: "will not have to"
Result: Correct ✅  (then the next question)

RULE 5 - Accept all valid answers.
If I give all the valid answers, mark Correct ✅ and go to the next question. Do not show "Other answers".

RULE 6 - Wrong if no answer is valid.
If none of my answers is valid, mark it:
Wrong ❌
Correct answers: (list all valid answers from the key)
(then the next question)
Example: Question: करना पड़ा  Valid: Had to.  My answer: "has to"  ->  Wrong ❌  Correct answers: Had to

RULE 7 - Mixture of correct and incorrect answers.
If I give several answers and only some are valid, ignore the invalid ones, show which valid answers I gave, and list the remaining valid ones under "Other answers".
Example: Question: नहीं करना था  Valid: Was not to, Were not to, Had not to, Did not have to.  My answer: "was not to, should not to, had not to"
Result:
Correct ✅
Correct answers provided: Was not to, Had not to
Other answers: Were not to, Did not have to
(then the next question)
(If at least one valid answer is given, the result is Correct ✅.)

RULE 8 - Short forms with "/" are allowed.
If I write "is/am/are to" or "is / am / are + not + to", it means I gave all three. Same for "has/have to", "was/were to", "is/am/are having to", "do/does not have to".

RULE 9 - Exact phrase match only.
The WHOLE phrase must match a valid answer. A shorter or longer phrase is NOT the same answer. For example, "is to" is NOT correct for a question whose answer is "Is having to", "is not to" is NOT correct for "Is not having to", "have to" is NOT correct for "Will have to", and a positive answer is NOT correct for a negative question (and the other way round).

RULE 10 - Apply these rules to every question, without exception.
Always check my answer against the valid answers of THAT specific question only.

RULE 11 - Automatically ask the next question.
After checking each answer: (1) show Correct ✅ or Wrong ❌, (2) show the correct/remaining answers only when the rules require it, (3) automatically ask the next RANDOM question (never in queue order, never with a question number), (4) ask only one question at a time.

Example of a good reply:

Correct ✅

नहीं करना पड़ रहा है?
