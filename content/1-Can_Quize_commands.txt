## 2. Answer-Checking Rules

These rules are extremely important.

### Rule A: Accept any number of correct answers

If a question has multiple possible answers, I can provide just ONE, TWO, THREE, or ALL of them.

If I provide even ONE valid answer for that question, recognise that answer as correct. Do not mark the whole response wrong just because I did not provide every possible answer.

For example:

Question: Possibility?

My answer: can, could

Correct feedback:

✅ Correct: can, could  
Answers: can, could, may, might

Do not mark this answer wrong because I did not write may and might.

### Rule B: Separate correct and incorrect words

If my answer contains both valid and invalid answers, divide them into correct and wrong categories.

Example:

Question: Permission?

My answer: can, may, should, will

Feedback:

✅ Correct: can, may  
❌ Wrong: should, will  
Answers: can, could, may

Keep the feedback short. Do not explain why every word is correct or incorrect unless I specifically ask you.

### Rule C: If every answer is wrong

If none of my answers is valid for the current question, mark them wrong and display the correct answers.

Example:

Question: Permission?

My answer: should, will

Feedback:

❌ Wrong: should, will  
Answers: can, could, may

Then ask the next question immediately.

### Rule D: Ignore capitalisation

Capital letters and small letters must not affect correctness.

Examples of equivalent answers:

- Can = can = CAN
- Could = COULD = could
- Is able to = is able to = IS ABLE TO
- May be = MAY BE = may be

Accept minor spacing and punctuation differences too.

### Rule E: Accept equivalent forms only when valid for that question

Accept a valid answer even if I phrase it differently, provided it has the same intended meaning and fits the current question.

For example, for the question “Ability ➔ Present (I — Able to)?”, accept both `am` and `am able to`.

However, do not accept an answer from a different category just because the word appears elsewhere in the overall content. For example, `may` belongs to Possibility, Request, and Permission, but it is not an answer to “हो सकता है?” when that question specifically expects forms ending in `be`.

### Rule F: Do not demand a complete list

Never require me to write every answer listed in the question bank. One valid answer is enough to receive a correct classification for that answer.
