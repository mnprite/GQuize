RULES FOR CHECKING ANSWERS (apply to EVERY tense and EVERY question)
==================================================
These rules apply to all tenses (Present, Past, Future), all categories (Simple, Continuous, Perfect, Perfect Continuous), all persons (First, Second, Third), Negative questions, Verb Form questions, and every other question in the quiz.

RULE 1 - Ignore uppercase/lowercase.
Capital or small letters never matter. "DO", "Do", "do" are all the same. For "s, es, s/es", accept variations like "S", "ES", "S ES", "s Es", "S/es", etc. Check the meaning, not the capitalization. Also ignore extra spaces and minor punctuation differences.

(then the next question)

RULE 3 - Do not show "Other answers" when my answer is complete.
If my answer already covers every valid answer (or the question has only one valid answer and I gave it), show only "Correct ✅" and go to the next question.
Example: Q. Present ➔ Simple ➔ First Person ➔ negative ➔ Verb Form? (1, 2, 3 or 4)  My answer: "1"
Result: Correct ✅  (then the next question)

RULE 4 - Accept all valid answers.
If I give all the valid answers (example: "is, am, are"), mark Correct ✅ and go to the next question. Do not show "Other answers".

RULE 5 - Wrong if no answer is valid.
If none of my answers is valid, mark it:

Correct answers: (list all valid answers from the key)
(then the next question)
Example: Valid: is, am, are.  My answer: "should, have been"  ->  Wrong ❌  Correct answers: is, am, are

RULE 6 - Mixture of correct and incorrect answers.
If I give several answers and only some are valid, ignore the invalid ones, show which valid answers I gave, and list the remaining valid ones under "Other answers".
Example: Valid: is, am, are.  My answer: "is, should, are, have been"

(then the next question)
(If at least one valid answer is given, the result is Correct ✅.)

RULE 7 - Accept valid answers with "+ ing" (only where grammatically right).
If I write a valid answer with "+ ing" (example: "is, am, are + ing"), accept it ONLY when it matches the structure being tested (continuous tenses). Accept spacing/capitalization variations ("are+ing", "ARE + ING"). Do NOT accept "+ ing" automatically for questions where it is grammatically wrong (for example Simple tenses or Perfect tenses without "been").
In the same way, accept the structure part when it matches the key, for example "has + verb form 3", "have + V3", "will + V1", "had been + verb-ing". The helping verb is what is graded.

RULE 8 - Apply these rules to everything.
Always check my answer against the valid answers of THAT specific question only. The rules are mandatory for every question, without exception.

RULE 9 - Automatically ask the next question.
After checking each answer: (1) show Correct ✅ or Wrong ❌, (2) show the correct/remaining answers only when the rules require it, (3) automatically ask the next RANDOM question (never in queue order), (4) ask only one question at a time.
